# Diagramme de Description Textuelle - Consulter les Campagnes de Sensibilisation

## **Cas d'utilisation : Consulter les Campagnes de Sensibilisation**

### **Acteur :**
- **Acteur principal :** Citoyen
- **Acteurs secondaires :** Administrateur (création des campagnes)

### **Pré-conditions :**
- Le citoyen est authentifié dans le système
- Des campagnes de sensibilisation sont disponibles
- Le citoyen a accès à l'interface des campagnes

### **Scénario nominal :**

1. **Accès aux campagnes**
   - Le citoyen clique sur "Campagnes" dans son tableau de bord
   - Le système affiche la liste des campagnes actives
   - Le citoyen voit les campagnes organisées par catégorie et date

2. **Navigation dans les campagnes**
   - Le système affiche les campagnes avec titre, description, date
   - Le citoyen peut voir le statut (active, terminée, à venir)
   - Le citoyen peut filtrer par catégorie (tri, recyclage, réduction déchets, etc.)

3. **Consultation d'une campagne**
   - Le citoyen clique sur une campagne qui l'intéresse
   - Le système affiche les détails complets de la campagne
   - Le citoyen voit le contenu : objectifs, conseils, informations, médias

4. **Interaction avec la campagne**
   - Le citoyen peut télécharger des documents (guides, brochures)
   - Le citoyen peut partager la campagne sur les réseaux sociaux
   - Le citoyen peut participer à des quiz ou sondages associés

5. **Suivi de participation**
   - Le citoyen peut marquer son intérêt ou sa participation
   - Le système enregistre l'engagement du citoyen
   - Le citoyen peut recevoir des mises à jour sur la campagne

### **Scénarios alternatifs :**

**1a. Aucune campagne active**
- Le système affiche "Aucune campagne en cours"
- Un message encourageant est affiché
- Le citoyen peut consulter les campagnes passées

**2a. Filtrage par type**
- Le citoyen filtre par type de campagne (tri, recyclage, compost, etc.)
- Le système met à jour l'affichage selon le filtre
- Le citoyen peut combiner plusieurs filtres

**2b. Recherche dans les campagnes**
- Le citoyen utilise la fonction de recherche
- Il saisit des mots-clés
- Le système affiche les campagnes correspondantes

**3a. Campagne avec contenu multimédia**
- La campagne contient des vidéos, images, infographies
- Le citoyen peut visionner/télécharger le contenu
- Le système adapte l'affichage selon le type de média

**3b. Campagne interactive**
- La campagne propose des quiz, sondages, défis
- Le citoyen peut participer directement
- Le système enregistre les réponses et fournit un score

**4a. Téléchargement de ressources**
- Le citoyen télécharge des guides PDF, brochures
- Le système vérifie l'espace de stockage
- Les téléchargements sont comptabilisés

**4b. Partage sur réseaux sociaux**
- Le citoyen clique sur "Partager"
- Le système ouvre les options de partage
- Un lien personnalisé est généré

**5a. Campagne avec récompenses**
- Certaines campagnes offrent des récompenses pour participation
- Le citoyen peut gagner des points, badges, ou prix
- Le système affiche le classement et les récompenses

**5b. Campagne avec événements**
- La campagne inclut des événements (ateliers, conférences)
- Le citoyen peut s'inscrire aux événements
- Le système gère les inscriptions et envoie des rappels

### **Post-conditions :**

**En cas de succès :**
- Le citoyen consulte les informations de sensibilisation
- Le citoyen peut télécharger des ressources utiles
- Le citoyen peut participer aux activités proposées
- Le système enregistre l'engagement du citoyen

**En cas d'échec :**
- Un message d'erreur est affiché
- Le citoyen peut réessayer ou contacter l'administration

### **Contraintes :**
- Maximum 50 campagnes affichées simultanément
- Taille maximale des téléchargements : 100MB
- Partage limité aux réseaux sociaux autorisés
- Participation limitée aux campagnes actives

### **Données d'entrée :**
- Filtres appliqués (type, statut, date)
- Mots-clés de recherche
- Sélection de campagne
- Actions d'interaction (téléchargement, partage, participation)

### **Données de sortie :**
- Liste des campagnes organisées
- Détails complets de la campagne sélectionnée
- Ressources téléchargeables
- Options de partage
- Résultats de quiz/sondages

### **Types de campagnes :**
- **Tri sélectif** : Apprendre à bien trier les déchets
- **Réduction déchets** : Conseils pour réduire la production de déchets
- **Compostage** : Guide du compostage domestique
- **Recyclage** : Informations sur les filières de recyclage
- **Événements** : Ateliers, conférences, actions collectives
- **Défis** : Challenges individuels ou collectifs

### **Fonctionnalités additionnelles :**
- Système de points et badges
- Classement des participants
- Recommandations personnalisées
- Notifications des nouvelles campagnes
- Historique de participation
- Certificats de participation
- Intégration avec calendrier personnel
